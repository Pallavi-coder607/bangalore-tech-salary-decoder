# 📊 Bangalore Tech Salary Decoder

## 📌 Project Overview
This project analyses Bengaluru tech salaries using **Python and Pandas**.  
The aim is to explore salary patterns, understand job role distributions, and extract insights from the dataset.

## 🛠️ Technologies Used
- Python 🐍
- Pandas
- NumPy
- Matplotlib
- Google Colab
- Jupyter Notebook

## 📂 Project Features
- Data loading and exploration
- Data cleaning and preprocessing
- Handling missing values
- Salary analysis based on job roles
- Data visualization
- Finding patterns in Bengaluru tech salaries

## 🚀 How to Run the Project

1. Clone this repository
```bash
git clone https://github.com/YOUR_USERNAME/bangalore-tech-salary-decoder.git
```
2. Open the notebook in Google Colab or Jupyter Notebook.
3. Install dependencies
```bash
pip install pandas
```
4. Run all cells from top to bottom.
